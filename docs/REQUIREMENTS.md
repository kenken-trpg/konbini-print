# 要件定義（確定版）

コンビニネットプリント向け 画像・PDF 一括変換アプリ

- 対象サービス: **セブンネットプリント** / **ネットワークプリント**（両方）
- UI: Streamlit
- 公開先: Streamlit Community Cloud

---

## 1. 目的

スマホ・PC上の画像・PDFを、両サービスに登録しやすい形式へ一括変換する。  
予約番号の取得や店舗操作は対象外。

---

## 2. 対応サービスと制約（準拠目標）

共通の安全目標:

| 項目 | 目標 |
|------|------|
| 1ファイル上限 | **10MB 以下** |
| 画像出力の第一候補 | **JPEG（RGB）** |
| 透過 | 不対応のため **不透明化**（既定: 白背景） |
| ファイル名 | 日本語・記号は維持。パス危険文字と絵文字のみ整理（セブンは記号・絵文字失敗の公式注意あり） |

### 2.1 セブンネットプリント（フォト用紙）

- 形式: 主に **JPEG**（Lサイズは JPEG のみの記載あり）
- 縦横比: **1 : 1.3 〜 1 : 1.5**
- ピクセル: 最小 352×251 / 最大 6144×4388
- 推奨: L 約 1074×1524〜 / 2L 約 1536×2138〜
- 端が数 mm カットされる前提で余白フィットを推奨

### 2.2 ネットワークプリント（画像）

- 形式: **JPEG / PNG**
- JPEG は **RGB**（グレースケール非対応の記載あり）
- 1ファイル 10MB、登録上限ファイル数あり（サービス側）
- 小さすぎる画像は拡大され画質劣化の恐れ

### 2.3 PDF（両サービス）

- セブン: PDF Ver 1.3〜2.0
- ネットワークプリント: PDF Ver 1.3〜1.7
- **共通出力目標: PDF 1.4 相当・非暗号化・シンプル構成**
- 1ファイル 10MB 以下
- ページ数はサービス差あり（変換時に警告表示）

---

## 3. 主用途

両方をサポートする。プリセットで切替。

1. **フォト用紙（L / 2L）**
2. **普通紙画像（A4 等）**
3. **ネットワークプリント スクエア（127×127mm）**
4. **はがき（100×148mm・画像）**
5. **PDF 文書・画像まとめ PDF**

---

## 4. 入出力

### 4.1 入力（必須）

| 種別 | 形式 |
|------|------|
| 画像 | JPEG, PNG, **WebP**, **HEIC/HEIF**, TIFF, BMP, GIF（先頭フレーム） |
| 文書 | **PDF** |

### 4.2 出力

| 用途 | 出力 |
|------|------|
| フォト用紙 | JPEG（RGB）、品質自動調整で ≤10MB |
| 普通紙画像 | JPEG（RGB）または PNG（不透明）、≤10MB |
| PDF | PDF 1.4 相当、非暗号化、≤10MB（超過時は分割提案） |

---

## 5. 変換・加工ルール

### 5.1 トリミング（デフォルト確定）

- **切れず余白あり（フィット）**
- 用紙アスペクトに収まるよう縮小し、不足分は余白（既定: 白）
- クロップはオプションで提供可（デフォルト OFF）

### 5.2 画像共通

- EXIF 向き補正
- 透過の塗りつぶし（既定: 白）
- フォト用紙プリセット時は縦横比・解像度・容量を検証し UI で OK/NG 表示
- JPEG quality を下げて 10MB 以内に収める（下限品質を下回る場合は警告）

### 5.3 PDF

- パスワード付きはエラー（解除はユーザー側）
- 複雑機能はフラット化・再保存で互換性を優先
- ページ数超過の可能性がある場合は警告（セブン 99p / NW は用紙により 30〜50p）
- 画像からの「まとめ PDF」も対応

## 6. 機能要件

### Must（MVP）

- [x] 複数ファイル一括アップロード（画像 + PDF）
- [x] HEIC / WebP 含む画像変換
- [x] PDF 変換・互換化（書き直し / ラスタライズ・非暗号化）
- [x] プリセット: セブン L / セブン 2L / NW L / NW 2L / 普通紙 A4 / PDF互換 / 画像まとめPDF
- [x] フィット＋余白（デフォルト）
- [x] 10MB 以内への自動圧縮
- [x] 変換結果プレビュー（解像度・容量・縦横比・サービス適合）
- [x] ZIP 一括ダウンロード
- [x] 一時ファイルの処理後削除（メモリ上処理、永続保存なし）
- [x] プライバシー注意表示（アップロード画像は永続保存しない旨）

### Should

- [x] 背景色指定
- [x] クロップモード切替
- [ ] ファイル名サニタイズ結果の表示
- [ ] PDF ページ分割提案

### Could（将来）

- [ ] 手動トリミング UI
- [ ] 高度な色管理（CMYK）
- [ ] Office 文書変換
- [ ] 予約フロー連携

---

## 7. 非機能要件

- Streamlit Community Cloud で動作すること
- 依存は可能な限り `requirements.txt` の Python パッケージに閉じる
- HEIC は `pillow-heif` 等で対応（Cloud 上で要検証）
- 制限値（MB・px・比率）は設定ファイル化し、公式仕様変更に追従しやすくする
- 公式サービスへの自動アップロードは行わない

---

## 8. UI 方針（概要）

1. サービス / 用途プリセット選択
2. ファイルアップロード
3. 変換オプション（フィット固定、背景色、出力形式）
4. 結果一覧（プレビュー・適合チェック）
5. 個別 DL / ZIP DL

---

## 9. 成功基準

- iPhone の HEIC と WebP を含む一式を、両サービス向け JPEG / 互換 PDF に一括変換できる
- フォト用紙プリセットで縦横比・容量が登録しやすい範囲に収まる（または明確に警告される）
- Streamlit Community Cloud 上で追加システムインストールなし（または最小）で動作する
